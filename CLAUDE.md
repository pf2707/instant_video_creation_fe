# MARKETING VIDEO CREATOR

Simple video creator or editor

## Features

First phase provide two main features

1. Split video to multiple videos
2. Insert videos to a video at specific positions (aka durations)
3. Decor a video

## Design & Technical Implementation

- Dashboard shows number of buttons corresponding to number of main features
- Video editor screen should be displayed as timeline
- Allow create and save projects for each editor

### Split video feature

- Button for upload a video from computer
- Show video on timeline with frames
- A tool allows user specific positions, mark them
- Export button will split them to multiple videos and show popup to select location to save
- Keep resolution and high quality
- User can select file extension is MP4 or MOV 

### Insert videos to a video at specific positions

- Button for upload a video from computer
- Show video on timeline with frames
- A tool allows user specific positions, mark them
- For each position, show a button to upload video from computer. No need to show uploaded video into the timeline.
- Export button will combine inserted videos to origin video and show popup to select location to save
- Keep resolution and high quality
- User can select file extension is MP4 or MOV

### Decor a video

#### Add Text Overlay
- Button for upload a video from computer
- Show video on timeline with frames
- Button allow add text overlay
- A text panel with simple functions such as: font size, font family, bold, italic, text color
